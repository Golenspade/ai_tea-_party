05 · Pi Agent Stack

AI 运行时（非本地裸 API）

ChatOrchestrator 创建 Pi Agent 实例；pi-ai 负责 Provider 注册与 HTTP；应用层 model 名经别名映射到官方 id。

06 · Persistence

SQLite 数据模型

Drizzle ORM + better-sqlite3。房间、角色、消息、人设、世界观、变量、设置 KV。
