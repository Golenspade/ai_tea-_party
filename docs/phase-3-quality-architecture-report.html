三、关键执行链路

1. 用户交互

前端输入消息、点击 Compact/Archive、回答 Ask、维护变量或 WorldInfo 条件。

2. API 边界

REST/SSE/WS 接收请求，校验 payload，统一调用 AppState。

3. 状态与领域服务

AppState 调用 compact、archive、variable condition、WorldInfo scanner、behavior rules。

4. Prompt 组装

PromptAssembler 注入历史摘要、四书结构、变量上下文、命中行为规则。

5. 持久化与回传

Repository 写入 SQLite 或 archive JSON，前端刷新侧栏状态。
